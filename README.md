# Multi Commit App

تطبيق Flutter بسيط لشرح طريقة رفع المشروع على GitHub على شكل أجزاء (commits) متكررة لأكثر من 30 مرة.

**محتويات المشروع**
- `pubspec.yaml` – تعريف الحزم
- `lib/main.dart` – كود التطبيق
- `scripts/` – سكربتات لإنشاء commits ورفعها

راجع سكربتات داخل مجلد `scripts` لتوليد عدة commits تلقائياً.
